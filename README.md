# MySQL Backup Automation

This project provides a simple automated MySQL backup solution using Bash scripting.

## Features
- Daily backup
- Compression
- Log recording
- Auto-delete old backups

## Usage
1. Edit database credentials in backup.sh
2. Add cron job:
   0 2 * * * /media/data/backup.sh
